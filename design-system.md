# CARPAIGN Design System

## Core Identity
Carpaign employs a **Luxury Gold & Tech Branding** aesthetic. The design should convey a premium, exclusive automotive experience blended with high-tech performance analytics.

## Color Palette

### 1. Night Shadow Black (Backgrounds / Dominant Base)
- **Hex**: `#111316`
- **Tailwind Variable**: `--background: 220 13% 8%;`
- **Usage**: Matte black base for all main surfaces, providing a deep canvas that allows other elements to stand out.

### 2. Liquid Luxury Gold (Premium Highlights)
- **Hex**: `#D4AF37`
- **Tailwind Variable**: `--primary: 46 65% 52%;`
- **Usage**: Used for cyber bronze/neon amber accents, buttons, and luxury highlights.

### 3. Soft Cream Ivory (Surface / Canvas)
- **Hex**: `#F5F5E9`
- **Tailwind Variable**: `--foreground: 60 30% 94%;`
- **Usage**: Clean asphalt color used for text clarity against the dark background.

### 4. Performance Deep Indigo (Tech Performance Accent)
- **Hex**: `#0A1C2C`
- **Tailwind Variable**: `--accent: 208 63% 11%;`
- **Usage**: Deep royal cyan for tech elements, charts, metrics, and attribution highlights.

### 5. Refined Titanium Gray (Neutral / Dividers)
- **Hex**: `#8D9096`
- **Tailwind Variable**: `--muted: 220 4% 57%;`
- **Usage**: Cool silver gray for sub-text, borders, and neutral elements.

## Typography
- **Heading & Body Font**: `Plus Jakarta Sans`

## UI Behaviors & Components
- **Theme**: Dark Mode strictly default.
- **Surfaces**: Use subtle glassmorphism (`backdrop-blur`) and thin borders (`border-white/10`) to create depth.
- **Accents**: Glowing effects on charts and primary interactive elements.
